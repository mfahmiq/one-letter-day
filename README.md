One letter, A to Z, standing for the word that describes the day. This entry sends **X**.

## The letter

**X — eXhausted.** The day ended with nothing left in the tank: the kind of tired that is funny only in retrospect, honest the moment you say it out loud. X is the sound the word starts with — the "ex" in exhausted — so the letter fits its word the way a good initial should.

## How it works

`main.py` (Python 3.13 standard library only, no network, deterministic) writes exactly one character to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It asserts the entry is a single A–Z letter before writing, and writes no newline, no gloss, no punctuation — the letter is the whole entry.

## Run it

```sh
python3 main.py
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"  # X
```
